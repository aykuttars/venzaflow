# Internationalization (TR / EN)

Tenancysoft supports **Turkish** (primary) and **English**. The tenant’s default language is stored on `Tenant.default_language` (`tr` or `en`).

## Behaviour

| Layer | How language is chosen |
|-------|-------------------------|
| **System default** | Turkish (`tr`) on login screen and for new tenants. |
| **Tenant** | `default_language` (`tr` \| `en`), set at seed as `tr`; changed only by **tenant admin** in **Settings** (`admin` department or `settings.write`). |
| **Login / me** | API returns `default_language`; all users get that language after sign-in (no per-user or toolbar override). |
| **API messages** | `Accept-Language` matches tenant UI language via `languageInterceptor`. |

## Frontend (Angular + ngx-translate)

- Translation files: `frontend/public/assets/i18n/tr.json` (complete) and `en.json`.
- Add keys under nested objects (`nav`, `common`, `products`, …).
- Templates: `{{ 'key.path' | translate }}` or `[label]="'key' | translate"`.
- Page titles: `<app-page-header moduleSlug="products" …>` (tenant custom name + i18n fallback) or `titleKey` for non-module pages.
- Tenant-specific module names: see [module-labels.md](./module-labels.md).
- Dynamic strings in TypeScript: `TranslateService.instant('key.path')`.
- Permission labels in UI: `permissions.<codename>` (DB `Permission.name` stays English).

Bootstrap: `app.config.ts` (`TranslateModule.forRoot`), `LanguageService`, `languageInterceptor` (`Accept-Language` header).

**Loader path:** use `/assets/i18n/` (absolute), not `./assets/i18n/`. A relative prefix breaks on routed URLs such as `/login` (requests hit `/login/assets/...` and return `index.html`).

Material date locale: `MAT_DATE_LOCALE` factory reads `LanguageService`.

## Backend (Django gettext)

- Settings: `LANGUAGE_CODE = "tr"`, `LANGUAGES`, `LOCALE_PATHS`, `LocaleMiddleware`, `RequestLocaleMiddleware`.
- User-facing strings: `from django.utils.translation import gettext_lazy as _`.
- Extract / compile:

```bash
cd backend
python manage.py makemessages -l tr
python manage.py makemessages -l en
python manage.py compilemessages
```

Docker image runs `compilemessages` during build (`gettext` package required).

## Adding a new UI string

1. Add the key to `tr.json` with Turkish text.
2. Add the same key to `en.json` with English text.
3. Use the key in the component template or `instant()`.
4. For API errors, wrap the message in `_()` in Python and re-run `makemessages` / `compilemessages`.

## Demo seed

`seed_demo` sets `default_language=tr` on demo tenants.

## Smoke checks

- Tenant `default_language=tr` → UI Turkish; weak password API error in Turkish with `Accept-Language: tr`.
- PATCH tenant to `en`, re-login → UI English.
- `Accept-Language: en` on login validation → English password policy message.
- `npm run build` and `compilemessages` succeed.
