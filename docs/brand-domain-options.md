## İsim köklerinin çağrışımları

### Venza-

- **Venezia / Venedik** → tarihte büyük ticaret merkezi; ticaret, iş, zenginlik
- **Venture / Advance / Avanza** → girişim, ilerleme
- **Bonanza** → bolluk, kazanç
- Genel ton: **profesyonel, premium, "işini büyüt"**
- Not: Toyota Venza araç modeli var (farklı sektör, düşük çakışma riski)

### Jova-

- **Jovial** → neşeli, sıcak, güler yüzlü
- **Jove / Jupiter** → liderlik, bolluk, iyimserlik
- **Nova** → yeni, parlak yıldız, taze başlangıç
- **Joven (İsp.)** → genç, dinamik
- Genel ton: **sıcak, ulaşılabilir, modern startup**
- Not: Jovia Financial (ABD kredi birliği) var (farklı sektör)
